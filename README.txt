UFC Countdown Timer - Instructions

1. Prerequisites:
   - Node.js must be installed. Install with: sudo apt install nodejs npm

2. Setup:
   - Open terminal in this folder.
   - Run: npm init -y
   - Run: npm install express axios cheerio cors

3. Start Server:
   - Run: node server.js
   - Server will start at: http://localhost:3000

4. Run the site:
   - Open 'index.html' in your browser.
   - It will show the live countdown to the next UFC event.

To stop the server: Press CTRL+C in terminal
To delete the server: Just delete the folder

You're now the boss of UFC event timing. LET'S GO!
